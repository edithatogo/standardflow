# Primary-repository adoption

## Objective

Migrate useful code, schemas, fixtures, tests and history into `edithatogo/standards_check` while preserving Apache-2.0 obligations and preventing duplicate standards authority.

## Acceptance criteria

- Exact source and proposed target revisions are recorded.
- Every migrated component has an owner, target role and compatibility test.
- Git history and licence notices are preserved.
- PRISMA/CONSORT/STROBE outputs have deterministic differential fixtures.
- Accessibility, rights, migration and rollback gates are explicit.
- Archival occurs only after observed cutover evidence.
